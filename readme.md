# Streamlit 계산기 프로그램

Streamlit을 활용하여 웹 기반으로 간단한 사칙연산을 수행할 수 있는 파이썬 계산기 프로그램입니다.

## 기능 및 특징
- **직관적인 UI**: '첫 번째 정수', '연산자', '두 번째 정수'를 각각 한 줄씩 입력받습니다.
- **예외 처리**: 
  - 정수가 아닌 값이 입력된 경우 오류 메시지 출력
  - `0`으로 나누기 시도 시 오류 메시지 출력
  - 허용되지 않은 연산자(`+`, `-`, `*`, `/` 외) 입력 시 오류 메시지 출력
- **간결한 구조**: `class`를 사용하지 않고 함수형/절차적 방식으로 간단하게 구현되었습니다.

---

## 설치 및 실행 방법

### 1. 요구 사항
- Python 3.7 이상
- 라이브러리: `streamlit`

### 2. 설치 방법
저장소의 의존성 패키지를 설치합니다.
```bash
pip install -r requirements.txt
```

### 3. 프로그램 실행
터미널(콘솔)에서 아래 명령어를 실행하여 Streamlit 앱을 구동합니다.
```bash
streamlit run app.py
```
*(참고: 파이썬 메인 코드가 `app.py`로 저장되어 있다고 가정합니다.)*
